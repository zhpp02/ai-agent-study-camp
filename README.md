# AI Agent 学习营（学习增强版）

## 功能
- 49 天学习计划与进度打卡
- 每日知识讲解与 Python 代码示例
- 每日 2 道测验，自动判分与答案解析
- 错题本：自动收集答错题目，可回到课程并标记掌握
- 每日学习提醒设置与浏览器通知权限申请
- 本地保存学习记录、笔记、测验和错题；支持 JSON 导入/导出
- PWA 离线缓存

## 部署
把 `index.html`、`manifest.webmanifest`、`sw.js`、`README.md` 放在 GitHub 仓库根目录，GitHub Pages 选择 `main` 分支和 `/(root)`。

## 提醒限制
本版本在网页打开期间检查提醒时间。网页关闭后的可靠定时推送需要服务端 Web Push，本版本不承诺 iPhone 后台准时推送。

## 数据
数据保存在当前浏览器 localStorage。清除网站数据或更换设备前，请先导出备份。
