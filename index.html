使用说明

这份计划怎么来的？

按你提供的《深入理解 AI Agent：设计原理与工程实践》（v2.0，2026-09-23）目录与章节组织，结合你反馈的 Python 零基础、每天 3–4 小时，以及招聘截图中的 Agent、RAG、Prompt、Workflow、企业应用开发要求制定。

关于 Python 预备周

PDF 引言列出了 Python、命令行、Git、JSON、REST API 等前置知识，但没有提供完整的 Python 零基础教程。因此第 1 周和第 2 周前半部分是配套预备练习，不是书中原文内容。

如何安装到 iPhone 主屏幕

此项目是 PWA 网页应用。需要先把 ZIP 中的文件部署到支持 HTTPS 的静态网站；然后用 iPhone Safari 打开网址，点“分享”→“添加到主屏幕”。首次打开并缓存后可离线使用。仅把 HTML 文件保存在“文件”App 中，不等同于完成 PWA 安装。

学习建议

每天先阅读指定页码，再理解概念、完成代码练习，最后写笔记。不要只打卡阅读；至少要能解释并复现当天的代码任务。

注意：7 周是高强度冲刺计划，目标是完成可演示的项目原型，不等于获得 1 年工作经验。书中各章页码采用目录标注的印刷页码。
